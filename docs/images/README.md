## Quick Setup

1. Run `npm run dev`
2. Open http://localhost:3000
3. Follow the guide in `docs/S_SCREENSHOTS_GUIDE.md`
4. Save screenshots here as PNG files
5. Optimize with `optipng -o5 *.png`
